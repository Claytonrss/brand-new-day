# Critério Portfolio-Grade

> Padrão mínimo para considerar o projeto bom o suficiente para portfólio.
> O verify usa estes itens como checklist visual. Se qualquer seção não
> produzir uma screenshot boa, ela volta para ajuste de Scene Spec.

## Checklist

- [ ] A primeira dobra impressiona sem o usuário precisar rolar.
- [ ] Cada seção gera pelo menos uma screenshot forte em mobile e uma em desktop.
- [ ] Mobile parece intencional, não uma versão comprimida do desktop.
- [ ] O usuário entende a experiência sem instruções visíveis de uso.
- [ ] O texto não compete com rosto, corpo ou detalhes narrativos.
- [ ] A página não parece template de landing, dashboard, SaaS ou demo de biblioteca 3D.
- [ ] O design continua forte com motion reduzida.
- [ ] A atribuição do asset é visível e elegante, sem parecer rodapé esquecido.

## Aplicação

Este checklist é avaliado junto com a rubrica de `visual-rubric.md`:

- Checklist = binário (passa/falha), verificado por screenshot.
- Rubrica = nota 1–5 por critério, com mínimos obrigatórios.

Falha em qualquer item do checklist **bloqueia PR**, independente da nota
média da rubrica.
