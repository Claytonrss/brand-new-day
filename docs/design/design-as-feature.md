# Design é a Feature Principal

> O MVP deste projeto não é "a página funcionar". O MVP é "a página ter
> presença visual de portfólio".

## Regras obrigatórias

1. **Implementação funcional sem impacto visual não está pronta.** Build verde
   com visual genérico = tarefa incompleta.
2. **O verify revisa estética, não só técnica.** Composição, hierarquia visual
   e impressão de portfólio fazem parte do aceite, junto com ausência de erros.
3. **O implement não cria componentes genéricos** antes de entender o
   enquadramento e o ritmo definidos nos Scene Specs.
4. **Composição vence conteúdo.** Em qualquer conflito entre adicionar mais
   conteúdo e melhorar a composição, priorizar composição.
5. **Tudo se justifica.** Qualquer nova seção, efeito ou texto precisa
   justificar como aumenta o impacto visual ou narrativo.

## Fluxo de retorno

```
visual abaixo do padrão → volta para Design Bible / Scene Spec → Look Dev
```

O fluxo de implementação permite (e espera) voltar para design quando a tela
não atingir o padrão visual. Isso não é falha de processo — é o processo.

## Critérios de aceite

- [ ] O plano e os Scene Specs declaram design como requisito de aceite.
- [ ] O fluxo de implementação permite voltar para design quando a tela não
      atingir o padrão visual.
